# DripDoodle Mobile 📱☕

An Expo + React Native app to capture images of your coffee cup and (soon) overlay fun AI-generated doodles.

## 🔧 Built With

- React Native
- Expo SDK 50
- TypeScript
- expo-camera (v16.0.18)

## 📸 Features

- Open camera in-app
- Take picture of your coffee cup
- Preview + retake
- Clean Git setup, .gitignore included

## 🚀 Getting Started

```bash
git clone https://github.com/yourusername/dripdoodle-mobile.git
cd dripdoodle-mobile
npm install
npx expo start
